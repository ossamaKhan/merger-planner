Upload monthly site workbook

Just pick the file. It reads Sheet1 with all its data. Required columns: Sites, Franchises, latitude, longitude; every other numeric column becomes a KPI automatically.

Months are detected automatically: from a Month / Period / Date column if the sheet has one (one file can hold many months), otherwise from the file name (e.g. Sites Oct 2026.xlsx), otherwise the current month. Upload one file per month, or one file with a Month column. In the planner you can then tick any combination of months. Re-uploading a month only replaces the regions in that file, so separate Central 5 / 6 / 7 files for the same month all stay.
