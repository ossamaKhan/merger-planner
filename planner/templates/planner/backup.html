Backup & restore

Use this every time you move to a new version of the project, so no planning work is lost.

  1. In the old version: Download full backup below.
  2. Unzip the new version, start it, open Backup and restore the file.

Coming from a version without this page? Restore its db.sqlite3 file (in the old project folder) directly; that works too. Simplest of all: copy the old db.sqlite3 into the new folder before starting it.
